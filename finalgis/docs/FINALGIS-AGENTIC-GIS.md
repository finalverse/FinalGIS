# Agentic geographic workflow

The implemented natural-language workflow is deliberately finite: analyze the pinned Montréal roads/roofs/elevation and prepare a260m scene. The planner selects a reviewed recipe; it does not synthesize an unrestricted processing program. The strict operations are inspect; clip_project(EPSG:2950,half_extent130m); road_buffer(radius2.5m); generate(height12m,terrain_grid33). Unknown fields/tools/CRS/units/parameters, omitted review, modified source bytes and existing outputs are refused. The native executor uses GDAL/PROJ for transforms/intersection, GEOS triangulation/buffering and a bounded mesh writer.

The real desktop sequence loaded45 roof outlines and93 roads, displayed the declared CRS, reviewed a typed plan and completed a165,964byte GLB with5046triangles/8589vertices. The first captured desktop run after the PROJ fix took193.655ms; it is not an AI latency measurement. Existing QGIS native reprojectlayer, vector geometry/buffer, raster provider and project save/reopen also passed independently on both tested runtime versions. Unimplemented tool families include spatial/network joins, drainage, arbitrary tool composition and research workflows; normal QGIS Processing remains available for professional use.
