# Canonical FWD

FWD 0.1 belongs to finalverse/finalverse/world-definition; this product only maps native workflow receipts to it through scripts/export_fwd.py. Native Core validates UUIDs, schemas, references, classifications, frames, transforms, asset hashes/sizes and its static GLB profile. FVP remains the binary interoperability protocol; JSON here is an immutable versioned file contract, not another wire protocol.

Both raw and Studio-refined definitions preserve existing Earth/Aetheria world UUIDs, generator/seed/version, source licenses/hashes, geometry classification and projected/local frame origin. No resident or mutable weather/entity state is embedded. Optional MutSea simulation bindings remain reference-only and are not created by this workflow. See canonical Core FWD-SPECIFICATION.md for bounds and supported optional lighting/material/environment domains.
